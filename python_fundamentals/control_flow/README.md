# Control flow: positive or negative

## Description

This exercise demonstrates conditional statements in Python. The script generates a random integer between `-10` and `10`, then identifies whether the number is positive, negative, or zero.

## Requirements

- Python 3

## Usage

From this directory, run:

```bash
python3 positive_or_negative.py
```

The output changes on each run because the number is generated randomly. Examples:

```text
7 is positive
```

```text
-3 is negative
```

```text
0 is zero
```

## Files

- `positive_or_negative.py`: generates and classifies a random integer.
